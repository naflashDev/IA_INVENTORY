# 🤝 Orquestación Multi-Agente

Frameworks, arquitecturas y librerías para coordinar flotas de agentes autónomos colaborativos o competitivos, handoffs de tareas y ejecución basada en grafos con estado.

---

| **LangGraph** | Multi-Agente | Motor de orquestación mediante grafos con estado, checkpoints, control humano y ejecución durable | Python, TypeScript | [langchain-ai/langgraph](https://github.com/langchain-ai/langgraph) |
