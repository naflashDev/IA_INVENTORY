# 🔍 Investigación, RAG & Recuperación de Información

Agentes de búsqueda profunda (Deep Research), extracción y síntesis de literatura, pipelines de embeddings, motores RAG corporativos y conectores de búsqueda web.

| Repositorio | Tipo | Descripción | Stack / Protocolo | Enlace |
| :--- | :--- | :--- | :--- | :--- |

| **LangChain** | Framework | Ecosistema de componentes modulares para RAG, recuperación semántica y orquestación de agentes | Python, TypeScript | [langchain-ai/langchain](https://github.com/langchain-ai/langchain) |
